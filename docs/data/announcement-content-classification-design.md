# 공고와 안내 게시글 분리 설계

## 분류

- `ANNOUNCEMENT`: 입주자·예비입주자 모집, 추가모집 등 사용자가 청약 여부를 판단할 모집 공고
- `NOTICE`: 당첨자·예비자 발표, 서류 제출·심사, 계약·입주 안내, 결과 발표 등 모집 이후 안내

## 처리 원칙

- 수집기는 두 유형을 모두 저장한다. 원문 URL, 수집 시각, 변경 이력은 유지한다.
- 제목 규칙으로 `NOTICE`를 자동 분류한다. 모호한 제목은 `ANNOUNCEMENT`로 보존해 누락을 피한다.
- 사용자 홈·공고 찾기·검색 필터·추천·카운트는 `ANNOUNCEMENT`만 조회한다.
- 관리자 검색은 두 유형을 모두 조회할 수 있어 수집 이력과 원문을 관리한다.
- 향후 관리 화면에 분류 변경 기능을 추가할 때까지는 제목 규칙 변경으로 재분류한다.

## 적용 기준

`NOTICE` 제목 패턴: 당첨자/예비자 발표·명단, 서류 제출·심사, 계약 안내, 입주 안내, 결과 발표.

자동 분류는 모집 여부를 추정하는 용도가 아니라 사용자 노출 대상을 줄이는 용도다. 잘못 분류된 게시글은 관리자가 원문을 확인해 규칙을 보완한다.
