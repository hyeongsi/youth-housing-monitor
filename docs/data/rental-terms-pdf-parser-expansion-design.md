# PDF 관리비·전환 조건 자동 추출 설계

> 상태: 1차 구현 대상 — `SEOUL_YOUTH_SAFE / PRIVATE_RENTAL_NOTICE` 파서

## 목표

현재 PDF 검토 화면에서 직접 입력할 수 있는 관리비·전환 조건을, 서울 청년안심주택 민간임대 공고문의 텍스트 레이어에서 초안으로 채운다. 확정 전 관리자가 PDF 근거를 확인하는 기존 원칙은 유지한다.

## 범위

- 대상: `SeoulYouthSafePrivatePdfParser`
- 관리비: `관리비` 또는 `공용관리비` 문구가 있는 행에서 원문과 명시 단위의 금액을 추출한다.
- 전환 조건: `전환`과 보증금·임대료 관련 문구가 함께 있는 행을 원문 그대로 추출한다.
- 값은 해당 PDF의 공급 주택형별 임대 조건 초안에 넣는다. 공통 문구가 여러 주택형에 적용될 수 있으므로 자동 근거 상태는 항상 `검토 필요`다.
- 금액 단위가 없거나 형식이 모호하면 원문만 채우고 정규화 금액은 비운다.

LH·SH 등 다른 기관 PDF는 표 구조와 용어가 달라 이 작업에서 추측해 적용하지 않는다. 기관별 샘플을 확보한 뒤 별도 파서와 회귀 테스트를 추가한다.

## 데이터 흐름

```text
PDF 텍스트 레이어
  → 관리비·전환 조건 후보 행 탐색
  → rentalOptions 관리비 원문·금액 / 전환 조건 초안 반영
  → PDF 페이지·원문·검토 필요 근거 생성
  → 관리자 확인·수정
  → 확정 시 SQLite rental_options 저장
  → 이후 PDF 확정·복원에서 변경 이력 생성
```

## 저장 규칙

| 초안 필드 | DB 컬럼 | 규칙 |
| --- | --- | --- |
| `managementFeeRawText` | `management_fee_text` | 관리비 관련 원문 전체 |
| `managementFeeWon` | `management_fee_won` | `원` 또는 `만원` 단위가 명시된 경우만 저장 |
| `conversionConditionText` | `conversion_condition_text` | 전환 관련 원문 전체 |

`DocumentImportService.normalizedSites`는 위 세 필드를 보존해야 한다. 값이 없는 경우 `null`로 저장하며, `0원`을 만들지 않는다.

## 검토·확정 규칙

- 자동 추출 근거는 모두 `NEEDS_REVIEW`다.
- 여러 주택형에 공통 후보를 적용한 경우 경고를 표시해 관리자가 적용 범위를 확인한다.
- 관리비는 금액을 정규화할 수 없어도 원문을 표시한다.
- 검토자가 원문·금액·전환 조건을 수정하면 기존 근거 무효화 및 수동 근거 절차를 따른다.
- 최초 확정은 사용자용 변경 이력을 만들지 않고, 이후 확정·복원에서 관리비·전환 조건의 차이만 `RENTAL_CONDITION` 이벤트로 저장한다.

## 완료 기준

1. 관리비 금액과 전환 조건 문구가 있는 서울 청년안심주택 민간임대 PDF에서 초안 필드와 PDF 근거가 생성된다.
2. 단위 없는 관리비 후보는 원문만 남기고 검토 필요 상태가 된다.
3. PDF 확정 뒤 관리비·전환 조건이 상세 DB 조회에 남는다.
4. 이후 값이 바뀌면 관리비·전환 조건 변경 이력이 각각 생성된다.
5. 기존 보증금·월세·면적·일정 추출과 PDF 확정 검증이 회귀하지 않는다.
