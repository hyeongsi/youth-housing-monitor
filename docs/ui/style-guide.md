# UI 스타일 가이드

## 적용 범위와 운영 원칙

현재 운영 화면은 `web/src/app.css`의 토큰과 `web/src/components/ui.module.css`의 공통 UI 규칙을 기준으로 사용한다. 새 화면·기능을 만들거나 스타일 관련 변경을 할 때는 이 문서를 먼저 확인하고, 결정된 예외나 새 규칙은 이 문서에 함께 기록한다.

## 시각 기반

- 배경: `--canvas`, 내용 표면: `--surface`, 보조 표면: `--surface-muted`
- 주 색상: `--primary` 한 가지를 주요 동작·현재 위치에만 사용한다.
- 상태색: 성공·주의·오류에만 `--success`, `--warning`, `--error`를 사용한다.
- 테두리: `--line`, 둥근 모서리: 큰 패널 `13px`, 입력·버튼 `9~10px`
- 그림자는 기본 사용하지 않는다. 선택된 탭이나 떠 있는 레이어에만 가볍게 사용한다.

## 타이포그래피와 여백

- 기본 글꼴과 크기는 `web/src/app.css`의 `:root`를 따른다.
- 페이지 제목 `h1`, 섹션 제목 `h2`, 카드 제목 `h3` 순서를 지킨다.
- 본문 설명은 `--muted`, `0.8rem`, 줄간격 `1.55`를 기준으로 한다.
- 페이지 본문 폭은 `1280px`, 일반 관리자 화면은 `1120px`를 넘지 않는다. PDF 3열 검토 작업대만 가독성을 위해 `1280px`까지 허용한다.
- 패널 내부 여백은 `22px`, 패널 사이 간격은 `18~20px`를 기본으로 한다.

## 컴포넌트

| 대상 | 규칙 |
| --- | --- |
| 주요 버튼 | `.official` 또는 기본 `button`, 파란 배경은 한 화면의 주 행동 하나에 우선 사용 |
| 보조 버튼 | `.secondary`, 흰 배경·기본 테두리 |
| 관리 화면 바로가기 | `.admin-import-link` 안에 버튼과 한 줄 설명을 함께 둔다 |
| 패널 | `.admin-panel`, `.search-panel` 등 공통 표면·테두리·반경을 사용 |
| 상태 | 배지 색만으로 구분하지 않고 한글 상태명을 함께 표시 |
| 목록 행 | 제목, 보조 설명, 우측 행동의 3영역을 기본으로 하고 모바일에서는 1열로 전환 |
| 관리자 작업함 | 상태 요약 → 필터 → 목록 순서로 두고, 한 행에는 다음 행동 버튼 하나만 둔다 |
| 관리자 일괄 편집 | 표에는 비교에 필요한 핵심 필드만 두며, 수정은 우측 패널 또는 상세 화면에서 처리한다 |

## 접근성·반응형

- 버튼·링크 최소 높이 `44px`
- `:focus-visible` 포커스 외곽선을 제거하지 않는다.
- 720px 이하에서는 다열 레이아웃을 1~2열로 줄이며, 행동 버튼은 전체 폭을 허용한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.

## 변경 기록

- 2026-11-12: 사용자 메인, 수집 관리, PDF 검토, PDF 분석 관리 화면에 공통 색상·버튼·패널 규칙 적용을 기준으로 확정.
- 2026-11-12: PDF 검토 화면을 공통 본문 폭·18px 패널 간격·22px 패널 여백으로 조정.
- 2026-11-12: 공고 데이터 관리 화면은 작업함·일괄 편집·반영 이력으로 나눈다. 작업함의 행은 주 행동 하나와 다음 작업 안내를 제공하고, 내부 상태 코드는 노출하지 않는다.
- 2026-11-13: 서비스·관리 메뉴는 동일한 주 메뉴 레벨에 배치한다. 모바일에서는 메뉴를 축소하거나 숨기지 않고 가로 스크롤로 모든 항목에 접근하게 한다.
- 2026-11-12: 작업함 요약은 4열 수치 버튼, 목록은 제목·상태·주 행동 3영역을 사용한다. 720px 이하에서는 요약 2열과 목록 1열로 전환한다.
- 2026-11-13: React 전환 후 공통 UI는 `web/src/components/ui.module.css`로 관리한다. 화면별 CSS를 `web/src/app.css`에서 추가로 분리할 때도 `section-heading`처럼 화면 간 충돌할 수 있는 범용 전역 선택자는 새로 만들지 않는다.
- 이후 사용자가 스타일 관련 지시를 하면 이 섹션에 날짜, 결정 내용, 영향을 받는 컴포넌트를 추가한다.
